Real-time object detection on the Windows desktop.

Bytron captures the screen, runs YOLO26 through TensorRT on your NVIDIA GPU, and draws the results on a transparent overlay. Frames stay in GPU memory from capture to inference.

Get started View on GitHub

Built around the newest frame

A queue would keep every frame and every bit of delay. Bytron keeps a small mailbox instead, always takes the newest capture, and runs several frames through the GPU at once.

GPU-resident frames

Captures go straight from a D3D11 texture into CUDA device memory. Only detection results return to the host.

Pipelined inference

Two to four frames run at once, each with its own CUDA stream and TensorRT execution context.

One preprocessing pass

Resize, letterbox, color conversion, normalization and layout change run in a single CUDA kernel.

CUDA graph replay

After a warm-up pass, the GPU work for a frame launches as one captured graph.

Two capture backends

Windows.Graphics.Capture by default, with DXGI Desktop Duplication as a fallback and a high refresh option.

Three outputs

A click-through overlay excluded from capture, a full-frame Vulkan window, or headless.

Get started

Requires Windows 11, an NVIDIA GPU, Visual Studio 2026, the CUDA Toolkit, TensorRT, the Vulkan SDK and vcpkg.

git clone https://github.com/CobraAitch/Bytron-Cuda.git
cd Bytron-Cuda

cmake --preset x64-release
cmake --build --preset x64-release

.\out\x64-release\Release\bytron.exe --onnx yolo26m.onnx
