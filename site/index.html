Bytron Benchmarks Architecture GitHub

Real-time object detection on the Windows desktop.

Bytron runs YOLO26 through TensorRT, with frames staying on the GPU from capture to inference.

Performance

A typical Python loop copies every frame to the CPU and back. Bytron skips those round trips. Measured on yolo26m at 640x640 on an RTX 4070 Ti.

Same model, same GPUTime per frame
Bytron1.65 ms
ONNX Runtime with CUDA, in a Python loop11.87 ms

Get started

Requires Windows 11, an NVIDIA GPU, Visual Studio 2026, the CUDA Toolkit, TensorRT, the Vulkan SDK and vcpkg.

git clone https://github.com/CobraAitch/Bytron-Cuda.git
cd Bytron-Cuda

cmake --preset x64-release
cmake --build --preset x64-release

.\out\x64-release\Release\bytron.exe --onnx yolo26m.onnx
